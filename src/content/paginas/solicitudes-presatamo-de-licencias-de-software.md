## Bienvenidos docentes y estudiantes de la Facultad de Ingeniería

Nos complace ofrecerles la posibilidad de solicitar licencias para las siguientes herramientas de software de ingeniería.

## Software de ingeniería

### HTZ

HTZ Communications es una herramienta avanzada para la planificación y optimización de redes de radio. Ofrece capacidades para el diseño de redes, análisis de cobertura, planificación de capacidad, análisis de tráfico, y más. [Documentación HTZ](https://www.htz-communications.com/)

### GAMS

GAMS (General Algebraic Modeling System) es un sistema de modelado algebraico de alto nivel para la optimización matemática. Permite modelar y resolver problemas de optimización lineal, no lineal y de enteros mixtos. [Documentación GAMS](https://www.gams.com/)

### PowerFactory

PowerFactory es un software líder para el análisis de sistemas de energía. Se utiliza para analizar sistemas de generación, transmisión, distribución e industriales, ofreciendo una amplia gama de funcionalidades desde aplicaciones estándar hasta avanzadas. [Documentación PowerFactory](https://www.digsilent.de/en/powerfactory.html)

### LabVIEW

LabVIEW es un entorno de programación gráfica que proporciona aceleradores de productividad únicos para el desarrollo de sistemas de prueba. Simplifica la integración de hardware y permite la visualización inmediata de resultados. [Documentación LabVIEW](https://www.ni.com/en-us/shop/labview.html)
