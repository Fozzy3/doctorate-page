## Curso: Programación Paralela con OpenMP

Este curso está dirigido a la comunidad académica y profesionales interesados en la computación de alto rendimiento. Ofrece una introducción práctica y conceptual al uso de OpenMP como API estándar para la programación paralela. El objetivo principal es capacitar a los participantes para dividir tareas de cómputo entre múltiples hilos en sistemas de memoria compartida, logrando así mejoras significativas en la velocidad de ejecución de sus aplicaciones.

### Detalles del curso

- **Docente:** Ing. Richar Javier Chía
- **Fecha y hora:** Miércoles 6 de mayo de 2026, de 6:30 p.m. a 9:30 p.m.
- **Metodología:** Virtual
- **Requisitos:** Conocimientos básicos en lenguajes de programación C o C++

### En este curso aprenderás

- Los fundamentos y conceptos clave de la arquitectura de memoria compartida.
- A utilizar las directivas de compilador y las funciones de la biblioteca OpenMP.
- Estrategias de paralelización para optimizar código escrito en C, C++ y Fortran.
- Ejemplos prácticos y casos de estudio para la implementación efectiva del paralelismo.

## Taller: Limpieza y Normalización de Datos con Python

Aprende a transformar datos desordenados en información confiable mediante técnicas modernas de limpieza, validación y análisis de datos utilizando Python y Jupyter Notebook.

### Detalles del taller

- **Docente:** Ing. Cristian Camilo Castro C
- **Fecha y hora:** Jueves 28 de mayo de 2026, de 2:00 p.m. a 4:00 p.m.
- **Metodología:** Virtual

Este taller combina fundamentos teóricos, ejercicios prácticos y casos reales para que los participantes desarrollen competencias en la identificación y corrección de problemas de calidad de datos, una de las etapas más importantes en proyectos de analítica, inteligencia artificial y ciencia de datos.

A lo largo del curso se abordarán conceptos como análisis exploratorio de datos (EDA), detección de valores nulos, registros duplicados, inconsistencias de formato, tratamiento de valores atípicos (outliers), imputación estadística, normalización de variables categóricas y construcción de procesos ETL (Extract, Transform, Load).

Además, los participantes aprenderán a interpretar métricas estadísticas fundamentales como media, mediana, moda, cuartiles, rango intercuartílico (IQR) y correlación, aplicándolas directamente sobre conjuntos de datos reales.

Como complemento, se introducen técnicas de visualización de datos mediante Matplotlib y Seaborn, permitiendo construir histogramas, boxplots, scatterplots, mapas de calor y matrices de correlación para apoyar la toma de decisiones basada en datos.
